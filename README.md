# Blue Marble Lite

Small pop-up displays timer and time until full pixels and pixel count for the next level. When inspecting a pixel, there's a button to inspect its location at the archive [Wplace Daily Archives](https://wplace.eralyon.net/en/).

[images here]

## Installation

You can use [Tampermonkey](https://www.tampermonkey.net) to run the userscript located [here](https://raw.githubusercontent.com/dinisafonsopinto/Wplace-Blue-Marble-Lite/refs/heads/main/tampermonkey.fetcher.js).

After installing Tampermonkey, click [here](https://raw.githubusercontent.com/dinisafonsopinto/Wplace-Blue-Marble-Lite/refs/heads/main/content.user.js) to download this userscript.
